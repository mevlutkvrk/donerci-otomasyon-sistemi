# Restaurant Management System #

A desktop-based Point of Sale (POS) and customer tracking application designed for small to medium-sized restaurants. This project was originally developed to practice GUI development and database integration.

# Features
- Order Management:  Take and manage daily restaurant orders efficiently.
- Customer Tracking: Keep simple records of customer interactions.
- Multi-Screen Interface: Desktop interface designed for easy navigation across different menus.
- Database Integration: Stores and retrieves data seamlessly.

# Tech Stack
* Language: Python
* GUI Framework: PyQt5
* Database: MongoDB

# About This Project
This is an educational project aimed at improving my skills in desktop application development, UI design with Python, and NoSQL database management. It served as a great hands-on experience for my software engineering journey.
